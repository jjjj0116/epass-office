1. 사무실 이용 방법

구역이용 방법
출입구오픈채팅 공지의 링크로 출근함. 출근 시 이름과 시각이 출근부에 기록됨. 사원증은 사용 기기에 저장됨
팀장 메신저출근 후 당일 업무를 먼저 확인함
내 자리주차별 업무 수행. 노션 따라 하기를 참고하여 Code 탭에서 실습함
팀장 자리업무 중 막히는 사항은 「업무 확인 요청」(질문 폼)으로 수시 제출함
결재함주차 업무 완료 후 「금일 결재 전 점검표」 작성 → 「결재 상신」(과제 폼). 결재 의견은 승인 · 보완 요청 · 반려 중 하나로 회신됨
대표실 · 회의실각각 3주차 · 4주차에 개방
퇴근당일 막힌 사항을 업무일지에 1줄 기록함

2. 인계 업무

주차업무비고
1주차10월 통장 · 카드 내역 정리양식 변환 도구 작성

4주차나만의 업무 포트폴리오 작성정직원 임명

3. 준수 사항

  1. 실제 회사 자료와 개인정보는 사용하지 않는다. 실습은 (주)이패스상사 자료로만 한다.
  2. 오픈채팅방에는 파일과 결과 숫자를 올리지 않는다.
  3. 검산 판정은 인수자가 직접 한다.

4. 문의

  1. 업무 확인 요청은 질문 폼으로 제출한다.
  2. 회신은 평일 24:00 전 일괄. 당일 18:00까지 접수분이 대상이며, 이후 접수분은 다음 평일에 회신한다.
  3. 공통 사항은 오픈채팅, 개별 사항은 이메일로 회신한다.
  4. 급한 문제는 오픈채팅에 바로 올린다.

      1. 파일별 숫자 (2·6단계)

      열어 볼 파일04_산출물/표준거래표_〔파일〕.csv, 전표초안_〔파일〕.csv, 질의목록_〔파일〕.md
      볼 것표준 거래표의 건수와 입금·출금 합계, 전표 초안 행 수, 질의 목록 행 수. 카드는 이용금액을 출금 칸에 적어요.
      실무라면통장은 인터넷뱅킹 거래내역, 카드는 카드사 이용내역
      • 통장: 인터넷뱅킹 거래내역 조회(10월 1일~31일)의 입금·출금 건수와 합계
      • 카드: 카드사 홈페이지 이용내역 조회의 10월 이용 건수와 이용금액. 청구서 금액은 쓰지 않고, 승인 취소 건은 뺀다
      • 전표 초안 행 수: 회계프로그램에 입력한 10월 전표 건수
      • 질의 목록 행 수: 담당자 확인을 기다리는 미결 항목 목록
      파일건수입금 합계출금 합계전표 초안 행 수질의 목록 행 수

      2. 여섯 파일 합친 숫자 (8단계)

      열어 볼 파일04_산출물/전표초안_2026-10.csv, 질의목록_2026-10.md
      볼 것은행과 카드는 더하지 않고 따로 적어요.
      실무라면9월 말 잔액 + 입금 − 출금 = 10월 말 잔액
      • 은행: 통장 화면의 9월 말 잔액과 10월 말 잔액으로 위 식이 맞는지, 장부의 보통예금 잔액과 통장 잔액이 같은지(은행 대사)
      • 카드: 카드사 이용내역 조회의 10월 이용금액 합계
      • 계정 칸이 빈 행: 마감 전에 남은 미결 항목 수
